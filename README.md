# Web Scraping & Automation

Scripts de scraping y automatización para extracción de datos.

## Ejemplos incluidos
- Scraping de precios con exportación a Excel
- Monitor de cambios en páginas web
- Automatización de formularios

## Tecnologías
- Python
- requests / BeautifulSoup / Selenium
- pandas para datos
- openpyxl para Excel

## Casos de uso
- E-commerce: comparación de precios
- Investigación: recolección de datos públicos
- Monitoreo: alertas de cambios
